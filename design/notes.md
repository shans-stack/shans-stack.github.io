# 第四轮 · 安静的地铁图：五条线、三套配色

产出：
- `a2-macaron/`、`a2-muted/`、`a2-oldmoney/`：各有 `home.html`、`topic.html`、`shots/`。
- `src/`：唯一的源文件。`home.src.html`、`topic.src.html` 是页面，`pal.py` 是三套色值，`python3 src/build.py` 一次生成三个目录。三个目录里的页面逐字节相同，只有 `<html data-palette>` 的默认值不同。
- 每页底部有「配色：马卡龙 / 低饱和 / 老钱风」切换，只改颜色（老钱风同时换标题字体）。选了别的配色后，站内的首页与知识点页链接会带上 `?palette=`，跳过去颜色不变；地址里写 `?palette=muted` 也能直接打开某一套。

## 五条线与站

从上到下。表里「列」是从左到右的位置（0 到 9），大致是先学后学的顺序。

| 线 | 自己的站 | 换乘站 |
|---|---|---|
| 1 AI 应用 | 推理服务、Agent、Dynamo、RAG、KV Cache | 向量检索 |
| 2 数据 | 数据湖、数据管道、训练数据集 | 检查点、向量检索 |
| 3 计算 | GPU 与 HBM、NVLink、训练集群 | RDMA、分布式训练、检查点、GPUDirect Storage |
| 4 网络 | InfiniBand、RoCE、交换机拓扑、拥塞控制 | RDMA、NVMe-oF、分布式训练、GPUDirect Storage |
| 5 存储 | NVMe、纠删码、并行文件系统、对象存储、数据缩减、KV Cache 卸载 | RDMA、NVMe-oF、GPUDirect Storage |

共 27 个站：21 个只在一条线上，6 个换乘站。

| 换乘站 | 跨的线 | 依据 |
|---|---|---|
| 向量检索 | AI 应用、数据 | RAG 靠它取回资料；它本身是一种数据索引 |
| 检查点 | 数据、计算 | 训练过程写出、恢复训练时读回的数据 |
| 分布式训练 | 计算、网络 | 多机训练靠网络做梯度同步 |
| RDMA | 计算、网络、存储 | GPU 机器之间通信、存储协议（NVMe-oF、并行文件系统客户端）都跑在 RDMA 上 |
| NVMe-oF | 网络、存储 | 通过网络访问远端 NVMe 盘 |
| GPUDirect Storage | 计算、网络、存储 | GPU 显存经网卡直接读远端存储，不经过 CPU 内存 |

规则：每个胶囊只跨它真正停靠、且上下相邻的线，跨过的每条线在这一列都没有别的站。`src` 里的数据另用脚本查过：同一列同一条线上没有两个站，每个胶囊跨的线都连续。

**KV Cache（AI 应用和存储，中间隔着数据、计算、网络三条线）**：不画胶囊。改成两个站：AI 应用线上的「KV Cache」和存储线上的「KV Cache 卸载」，两站放在同一列（最右一列），各带一个用该线颜色画的虚线圈；鼠标移到其中一个，两个一起变实线、站名加下划线。图例写「虚线圈：同一主题，另一站在不相邻的线上」，图下说明写明为什么不画胶囊。知识点列表和手机竖排里，两站后面都标「另见 …」。这样不会有一条线看起来停了它其实不停的站。

数据湖与对象存储、训练数据集与并行文件系统也有关系，但同样隔了好几条线，这一版不画，免得虚线圈泛滥。

## 讲稿路线

路线仍是算出来的：沿线走、只在换乘胶囊里换线，对整场讲稿一起求最短路。这一版换乘只允许在胶囊内相邻的两条线之间进行。为了画出来不走回头路，两场讲稿的站序随新布局调整：

| 讲稿 | 站序 | 结果 |
|---|---|---|
| AI 集群入门（6 站 15 分钟） | GPU 与 HBM → NVLink → RDMA → RoCE → 分布式训练 → 检查点 | 换乘 2 次，一路向右 |
| 数据怎么喂给 GPU（5 站 12 分钟） | 对象存储 → 并行文件系统 → NVMe-oF → RDMA → GPU 与 HBM | 换乘 2 次，一路向左，终点是 GPU |

RDMA 仍是第一场的第 3 站、第二场的第 4 站，知识点页上的「出现在讲稿」不用改。

选中讲稿时：路线沿哪条线走，那一段就用那条线的颜色加粗（13px）；在胶囊里换线的竖段用墨色；途经和停靠的胶囊描粗；序号是浅底圆圈，圈的颜色是停靠那条线的颜色，数字用墨色。其余线降到约 26% 不透明，其余站约 32%。不再有单独的紫色。

### 文字对比度

三套的正文墨色对底色都在 13:1 以上，最浅的辅助文字（`--ink3`）对底色 4.9 到 6.4、对卡片 5.2 到 5.9，均过 4.5:1。线条对底色最低 2.35:1（马卡龙浅色的杏色）。

## 颜色出现在哪

只在这四处，其余保持 A 版的灰阶：

1. **地铁图的线**：五条线、线两端的符号、左侧线名旁的符号；选中讲稿时的彩色路线段和序号圈。
2. **知识点所属线的标记**：首页「按线路找知识点」每列标题的符号和短色条，讲稿卡片、换乘站清单、最近新增、知识点页面包屑和「先看／接着看」里的线路符号，手机竖排的线。
3. **知识点页标题下的细色条**：4px，按 RDMA 停靠的三条线分成计算、网络、存储三段，从左到右对应从上到下。
4. **步骤进度**：左侧步骤栏（画成网络线的一小段）和底部进度条用网络线的颜色，做过的站实心，当前站实心加墨色外圈，没到的站空心灰。

配色切换按钮里的五格小色块是例外，它的作用就是预览颜色。

## 和 A 版相比改了什么

- 四条灰阶线改成五条彩色线，顺序从上到下是 AI 应用、数据、计算、网络、存储。线与线的区分靠颜色加线端符号（新增一个表格形的「数据」符号，原来的节点图符号给了 AI 应用）。
- 站重排成 10 列 27 站，换乘站从 5 个改成 6 个，KV Cache 用「两站加虚线圈」的画法。
- 首屏导语、线路图说明、图例、地图的读屏说明都改成五条线的说法。
- 线路图行距从 100 收到 90，让 1280 宽的首屏仍然放得下整张图和讲稿选择按钮。
- 选中讲稿：原来整条路线是紫色，现在每段用所在线的颜色，换乘竖段用墨色，序号圈改为浅底加线色描边。按钮、讲稿卡片的选中状态改用墨色描边。
- 原来唯一的紫色全部取消：品牌方块右下角改成灰，焦点框改墨色，RDMA 示意图里快的那条路改成墨色实线（慢路仍是灰色虚线）。
- 「按线路找知识点」从 4 列改 5 列（1100 宽以下 3 列，720 宽以下 1 列）。
- 手机竖排：五段线各用自己的颜色；讲稿序号只出现在路线真正停靠的那条线上（换乘站在其他线上不重复编号）；KV Cache 两站后面写「另见」。
- 知识点页：标题下的 2px 黑线换成三段色条；面包屑写「计算线、网络线、存储线都停这一站」，三个符号上色；「先看」改为 GPU 与 HBM 显存、InfiniBand 怎么组网，「接着看」改为 RoCE、NVMe-oF、GPUDirect Storage。
- 页脚加配色切换。

另外往页面里临时注入脚本，在 headless shell 里量了：1280 和 960 宽、中英文、选中与未选中路线时，地铁图上的站名之间、站名与胶囊之间没有重叠（英文最小水平间距约 13px，是加粗后的「Parallel FS」和「Object storage」）；400 宽首页和知识点页都没有横向滚动；配色切换点一下后线色、底色、标题字体都换了，地址也带上了参数。

按截图修过的问题（排列时还预先避开了两处：RDMA 不放在数据管道正下方，免得两个站名上下挨着像一个站；拥塞控制放到最右一列，免得英文站名和交换机拓扑相撞）：
1. 第一版行距 100，地图在 1280 首屏放不下，收到 90。
2. 第一版两条讲稿都走回头路（「数据怎么喂给 GPU」在存储线上先往左再往右，压在同一段上），「AI 集群入门」换乘 4 次。重排列位置、调整站序后，两条路线都是单向的，各换乘 2 次。
3. 深色模式下没选中的线太暗，不透明度从 22% 提到 26%。

没做到或要留意的：
- 五种线色亮度接近，主要靠色相区分；色弱用户要靠线端符号和左侧线名认线。马卡龙浅色的杏色只有 2.35:1，投影上偏淡。
- 960 到 900 宽之间地图缩小，站名约 11px，再窄切换为竖排。
- 「数据怎么喂给 GPU」不再经过 GPUDirect Storage（新布局下它在 RDMA 右边，走它要回头）。要把它放回讲稿，得改站序或挪列。
- 除「RDMA 为什么快」外，知识点链接仍是占位。没运行任何第三方脚本，没有真机测试。
